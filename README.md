# Andrea Ragalzi — Portfolio

Static, mobile-first portfolio for Andrea Ragalzi, a Backend Engineer based in Málaga.

It presents five years of total software development experience across insurance and industrial automation, focused on Python backends, REST APIs and system integrations. Professional experience includes Python, Flask, AWS serverless applications and enterprise Java/Spring Boot.

The portfolio also features Document Intelligent Hub, a personal FastAPI/Next.js project focused on applied RAG and source-grounded document search.

The site is built with semantic HTML, plain CSS, and a small JavaScript file.

Public website: <https://andrea-ragalzi.github.io/>

## Silver forest banner

The profile panel uses a decorative inline SVG in `index.html`, animated by `assets/css/styles.css`. The path light, flame and trees use slow CSS animations; `prefers-reduced-motion` keeps the complete scene static. All profile text remains HTML, and the decoration cannot intercept link interaction.

`assets/images/og-image.svg` is the editable source for the matching static 1200×630 social image, `assets/images/og-image.png`. Update the SVG text or artwork and render it at its native dimensions when refreshing the PNG.
