# Andrea Ragalzi — Portfolio

Static, mobile-first portfolio for Andrea Ragalzi, a backend-focused Software Engineer based in Málaga.

It presents five years of software development experience across industrial automation and enterprise insurance, with a focus on backend development, REST APIs, integrations, automated testing, and maintainable services. Python/FastAPI is the primary backend stack, complemented by professional Java/Spring Boot experience and current full-stack work with Next.js and TypeScript.

The portfolio also features Document Intelligent Hub, an independent full-stack project focused on applied RAG and source-grounded document search.

The site is built with semantic HTML, plain CSS, and a small JavaScript file.

Public website: <https://andrea-ragalzi.github.io/>
